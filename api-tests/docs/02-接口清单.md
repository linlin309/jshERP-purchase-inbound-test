## 一、鉴权与会话

- 登录：`POST /user/login`。
- 会话：`GET /user/getUserSession`。
- 退出：`GET /user/logout`。
- 受保护接口统一带请求头 `X-Access-Token: <data.token>`。
- 前端登录时发送 `password = md5(明文密码)`；后端直接按该值比较，接口自动化在 `client.py` 内做 MD5。
- 验证码由 `checkcode_flag` 控制；当前为 `0`，`code`、`uuid` 可传空字符串。

## 二、通用响应形态

大多数接口返回 `BaseResponseInfo`：

```json
{"code": 200, "data": {}}
```

- `code=200` 表示请求处理成功；`code=500` 可能是被捕获的未知异常或通用失败，不一定是稳定的业务码。
- 部分写接口成功时返回 `{"code":200,"msg":"操作成功"}`，**没有 `data`**（如 IF-06）。
- 列表接口可能返回 `{code, data: {rows, total}}`。
- 个别接口返回原始 JSON 数组（如供应商下拉），不套 `code/data`。
- **已实测的例外**：登录失败返回 `{"code":200,"data":{"msgTip":"user password error"}}`，HTTP 仍为 200，且没有 token。判断登录成功不能只看 `code`，必须看 `data.token`。
- 业务校验失败通常是 HTTP 200 + 非 200 的业务码（实测新增缺结算账户返回 `code=8500007`）；HTTP 500 主要是未登录/坏 token 时 `LogCostFilter` 返回的纯文本 `loginOut`，不是通用业务错误。
- 不能默认“HTTP 200 就是成功”，也不能把 HTTP 500 当成业务失败；M2 统一错误断言。

## 五、关键请求示例

### 5.1 登录

```json
{
  "loginName": "jsh",
  "password": "<md5(123456)>",
  "code": "",
  "uuid": ""
}
```

示例中的账号仅说明字段；实际值以 `.env` 和根 README 为准。密码必须是 MD5，不是明文。

### 5.2 新增采购入库单

`info` 和 `rows` 都是字符串，不是嵌套对象：

```json
{
  "info": "{\"type\":\"入库\",\"subType\":\"采购\",\"number\":\"API-20261109-0001\",\"operTime\":\"2026-11-09 10:00:00\",\"organId\":1,\"accountId\":17,\"discountLastMoney\":0,\"otherMoney\":0,\"deposit\":0,\"changeAmount\":0,\"debt\":0,\"totalPrice\":-100,\"remark\":\"api smoke\",\"status\":\"0\"}",
  "rows": "[{\"barCode\":\"1001\",\"depotId\":14,\"operNumber\":1,\"unitPrice\":100,\"allPrice\":100,\"taxRate\":0,\"taxMoney\":0,\"taxLastMoney\":100}]"
}
```

要点：

- 前端提交的 `totalPrice` 是负数（`0 - 明细金额合计`），`changeAmount` 也为负；接口侧实际预期在 M2 用真实单据校准。
- `accountIdList`、`accountMoneyList` 是 JSON 字符串；多账户场景使用（手工 CASE-42 的 17/18）。
- `depotId=14`、`barCode=1001` 是演示数据示例，不是通用常量；M2 从 IF-03/IF-05 动态取。
- `info.status`：`"0"` 未审核，`"1"` 已审核；创建时一般传 `"0"`。

### 5.3 审核 / 反审核

```json
{"status": "1", "ids": "123"}
```

`status=1` 审核，`status=0` 反审核；`ids` 是逗号分隔的主表 id 字符串。

### 5.4 按单号查详情 / 查库存

```text
GET /depotHead/getDetailByNumber?number=API-20261109-0001
GET /depotItem/findStockByDepotAndBarCode?depotId=14&barCode=1001
```

### 5.5 系统配置

先 `GET /systemConfig/getCurrentInfo` 取当前对象，改一个字段后把整个对象 `PUT /systemConfig/update`。配置是全局的，M4 才启用，且必须恢复原值。
